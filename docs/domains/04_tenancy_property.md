# Tenancy and property

VIDHAAN source-linked research guide. Author: Qaiser Amin Ganaie.

Collected scope: Central property-transfer and lease provisions, plus real-estate regulation and promoter/allottee provisions.

Facts needed for case-specific research: State or union territory, property use, tenancy type, agreement, rent, transaction dates and any notices.

Coverage gaps: State rent-control, tenancy, land-revenue and local real-estate rules are not collected. Central lease passages alone cannot decide a state eviction question.

## Example local search

```bash
.venv/bin/python -m vidhaan.cli search 'Find the Transfer of Property Act definition of a lease.' --domain 'Tenancy and property' --jurisdiction central
```

Windows uses `.venv\Scripts\python.exe`. Effective-date filters exclude unknown versions. Reviewed research currently returns a gap.
