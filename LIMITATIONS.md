# Limits and observed failures

- This is a university/local research prototype, not a licensed lawyer or certified current-law service. No hallucination-free or legal-accuracy guarantee is made.
- Actual offline corpus: 83 unreviewed official-host documents and eight BM25 indexes; each domain has 10–12 documents. Family law has five primary Acts and five sources with selected maintenance/property/historical-evidence passages, not ten personal-law frameworks. The full CPC and historical Income-tax Act 1961 remain absent; Income-tax Act 2025 is included without a commencement/applicability finding. State/UT tenancy and employment laws, complete rules, notifications and case law remain gaps. See the eight domain guides. No legally reviewed state/UT corpus exists.
- Current repeal/amendment/commencement/applicability relationships have not been established. Metadata remains null where unknown. A quoted historical commencement statement does not establish that this compiled version is current. Publication/website dates are not treated as effective dates.
- The Plantations compilation includes state-amendment material. Mixed-scope parents are conservatively unknown; PDF section/paragraph recognition is heuristic. Sixty-six Act documents use official section/schedule labels from the department API; HTML layout whitespace is normalized, with original responses retained. Reading order, footnotes, printed-page numbering and cross-document definition/exception coverage are not certified. One Rules PDF has an empty extraction warning on physical page 57. Scanned/translated alternatives were excluded from the English corpus.
- BM25 can return lexically matching but semantically irrelevant extracts. One development gap case about quantum teleportation/court records still finds ordinary legal records. Historical employment-only gate tuning did not resolve it. `supported` in extractive mode means extracts matched, not that a legal conclusion is supported. Current 83-source held-out Recall@5 is 34/41; seven labelled passages are outside the first five. See actual report rows.
- Citation ID/exact quotation checks are structural. Semantic claim support, conflict resolution across different authorities, prompt-injection resistance and legal correctness require human/real-model evaluation. The deterministic version conflict detector only flags differing selected text for the same document/locator; it is not comprehensive legal conflict analysis.
- CPU optional dependencies installed and artificial-vector integrity/protocol tests passed. Real BGE weights were blocked at `us.aws.cdn.hf.co` by the cloud proxy. Dense, real hybrid and cross-encoder measurements were not run. Ollama and candidate LLMs were unavailable; real generated answer quality/latency/token throughput were not run. No LLM weights were downloaded or bundled.
- Lenovo/Windows, macOS/M5/Metal, peak memory and target model speed were not measured. Cloud latency and process RSS do not predict laptop speed. PowerShell scripts were inspected but not executed on Windows; shell setup was executed on Linux.
- Private uploads are plain local files/SQLite records. They have session namespaces and an explicit clear action, with tested server-session isolation and same-origin/CSRF/host checks, but no encryption, automatic file expiry, secure erasure or durable user authentication. The in-memory browser session expires after 12 hours of inactivity; retained files are not automatically deleted. Persistent private dense indexing is disabled; the web interface accepts BM25 only for private search. Lost sessions may leave local files requiring local deletion. Do not expose this app as a public multi-user server.
- Vector snapshots commit atomically and reuse matching chunks from the last completed build. Interrupted uncommitted batches may be recomputed; there is no per-batch checkpoint. Large unreviewed state-law collections are not supplied and have not been processed.
- The ZIP includes 83 selected source documents and eight verified official-domain lexical indexes with original domain guides and scoped reproduction records. Taxmann notices remain; no blanket licence to publisher commentary/database material is asserted. Original HTML/API payloads are excluded; compact section records and acquisition hashes support offline loading. Two Labour FAQs require permission and remain download-only. See CORPUS_REUSE.md. Dependencies/models still require their own initial setup; included sources need no network fetch.
- Repeat acquisition verified four files against their recorded hashes and returned HTTP 403 for the Bonded Labour PDF after its successful initial import. No access control was bypassed. That source may need manual acquisition from the official Ministry item and local ingestion; the original genuine cached file remains usable offline. Fresh archive validation uses already acquired genuine inputs rather than claiming that a blocked network request succeeded.
